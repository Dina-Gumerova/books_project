# Каталог книг

Учебное Django-приложение по варианту «Информация о книгах, JSON».
На странице есть карточки книг, выбор жанра, форма добавления и загрузка файлов.
Оформление сделано обычным HTML и CSS, без дополнительных библиотек.

## Запуск в Windows

1. Полностью распакуйте архив, например в папку `Documents\books_project`.
2. Установите Python 3.12 или новее. При установке отметьте `Add Python to PATH`.
3. Откройте папку проекта и запустите `start.bat`.
4. При первом запуске потребуется интернет: скрипт создаст `.venv` и установит Django.
5. Дождитесь строки `Starting development server`, затем откройте в браузере
   [http://127.0.0.1:8000/](http://127.0.0.1:8000/).

Пока работает сайт, окно скрипта должно оставаться открытым. Остановка — `Ctrl+C`.
Если порт 8000 занят, используйте ручной запуск с портом 8001.

## Запуск вручную

В терминале из папки с файлом `manage.py`:

```text
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe manage.py runserver
```

На Linux/macOS вместо `.venv\Scripts\python.exe` используйте `.venv/bin/python`,
а при создании окружения — `python3`.

## Что реализовано

- Добавление книги через HTML-форму с сохранением в отдельный JSON-файл.
- Проверка обязательных полей, длины текста, года, жанра и количества страниц.
- Загрузка JSON-файла в папку `data/books` с проверкой содержимого.
- Автоматическая генерация имени файла через UUID.
- Удаление временного файла при ошибке проверки.
- Чтение всех JSON-файлов из папки и вывод книг на страницу.
- Сообщения об отсутствии файлов и о поврежденных файлах.
- Фильтр по жанрам, подсчет книг и авторов, среднего количества страниц.
- Скачивание одного файла или всех книг в одном JSON-файле.

Используется JSON, как указано в выбранном варианте задания. XML не реализован.
База данных не нужна: данные хранятся в JSON. Выполнять миграции не требуется.
Проект настроен для локального учебного запуска.

## Формат файла

```json
{
    "books": [
        {
            "title": "Новая книга",
            "author": "Иван Иванов",
            "year": 2020,
            "genre": "Роман",
            "pages": 200,
            "description": "Краткое описание"
        }
    ]
}
```

Обязательные поля: `title`, `author`, `year`, `genre`, `pages`.
Поле `description` можно не указывать. Дополнительные неизвестные поля отклоняются.
Название — до 200 символов, автор — до 100, описание — до 1000.
Год — целое число от 1 до текущего года, страницы — от 1 до 10000.
Жанры: Роман, Повесть, Рассказ, Фантастика, Учебная литература, Другое.
Файл должен быть в UTF-8, не больше 1 МБ и содержать от 1 до 1000 книг.

В `data/books/demo.json` уже есть три примера для просмотра.
Год и количество страниц в этих записях — условные данные учебного каталога.
В `examples/books.json` лежит отдельный пример для загрузки через сайт.
Повторный импорт добавляет еще одну копию записей, объединение дубликатов не выполняется.
Для проверки пустого каталога временно переместите JSON-файлы из `data/books`.
Файлы в `examples` на странице автоматически не отображаются.

## Файлы проекта

- `library/settings.py` — настройки Django и путь к папке с данными.
- `books/forms.py` — формы и проверка полей.
- `books/storage.py` — чтение, проверка и сохранение JSON.
- `books/views.py` — обработка запросов, каталог и скачивание.
- `books/templates/books/index.html` — страница сайта.
- `books/static/books/style.css` — оформление.
- `books/tests.py` — проверки основных сценариев.

## Проверка

```text
.venv\Scripts\python.exe manage.py check
.venv\Scripts\python.exe manage.py test
```

Тесты используют временную папку и не меняют книги в основном каталоге.

## GitHub

В архиве сохранена папка `.git` с последовательными локальными коммитами.
Даты коммитов соответствуют фактическому времени подготовки проекта.
На GitHub проект пока не опубликован.

Чтобы разместить его с сохранением истории:

1. Создайте пустой репозиторий на GitHub без README и `.gitignore`.
2. Откройте терминал в папке проекта.
3. Проверьте историю командой `git log --oneline`.
4. Добавьте адрес своего репозитория и отправьте код:

```text
git remote add origin https://github.com/YOUR_USERNAME/books_project.git
git push -u origin main
```

Замените `YOUR_USERNAME` своим именем на GitHub. Папку `.git` не удаляйте,
иначе локальная история коммитов потеряется. При загрузке файлов через браузер
история локальных коммитов не переносится.
